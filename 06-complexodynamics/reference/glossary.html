术语表

所有课程统一使用下列译法。notebook 原文是繁体，括号里注明原词。

术语英文 / notebook 原词定义首见
元胞自动机cellular automaton（細胞自動機）由一排（或一网格）离散格子组成，每格按同一条局部规则、同步更新状态的离散模型。第 1 课
初等元胞自动机elementary CA (ECA)一维、状态取 0/1、邻域为左中右三格的元胞自动机，共 2⁸ = 256 条规则。第 1 课
邻域neighborhood决定一个格子下一刻状态的那组格子；ECA 中为 (l, c, r)。第 1 课
规则号rule number把 8 种邻域的输出按 k = 4l+2c+r 排成二进制得到的整数；第 k 位就是邻域 k 的新状态。第 1 课
周期边界periodic boundary（週期性邊界）首尾相接，最左格的左邻居是最右格。torch.roll 天然实现它。第 1 课
复制边界replicate padding越界处用最近的边缘值填充；notebook 咖啡扩散所用。与周期边界对照。第 1 课（预告）
循环移位torch.rollroll(x, s)[i] = x[i − s]（下标取模）。s = 1 取左邻居，s = −1 取右邻居。第 1 课
高级索引advanced (integer) indexing用整数张量当下标，table[idx] 返回与 idx 同形状的张量，可以一次查完整行。第 1 课
复杂度（直观义）complexity / complextropyAaronson 要形式化的「有趣结构」的多少：初态和终态都低，中间高。严格定义见后续课程。第 1 课（动机）
熵entropy（熵）封闭系统中单调不减的量。Shannon 熵的定义与推导见第 2 课。第 1 课（动机）
惊讶度surprisal / self-information概率为 p 的结果发生时的信息量 −log₂ p。必然事件为 0。第 2 课
Shannon 熵Shannon entropy（Shannon 熵）惊讶度的期望 H = −Σ pᵢ log₂ pᵢ，单位 bit；约定 0·log 0 = 0。n 种结果时 H ≤ log₂ n，当且仅当均匀分布取等号。第 2 课
二元熵函数binary entropy functionh(p) = −p log₂ p − (1−p) log₂(1−p)；严格凹，h(1/2) = 1 为最大值，h(p) = h(1−p)。第 2 课
边缘分布marginal distribution只看单个格子取值、不看位置关系得到的分布。notebook 的 measure_entropy 量的就是它的熵，所以打乱一行熵不变。第 2 课
沿维度归约dim= 参数x.mean(dim=1)、x.sum(dim=1) 等沿指定维度运算，该维被消掉：(T, N) → (T,)。第 2 课
转换次数transitions（轉換次數），measure_spatial_complexity相邻两格取值不同的对数 T = Σ|xᵢ₊₁ − xᵢ|，最多 N − 1。只看长度为 2 的窗口，给交替 0101 打满分；随机行期望 (N−1)/2。第 3 课
压缩长度compressed length（gzip / zlib）把状态交给无损压缩器后的输出字节数。是 Kolmogorov 复杂度 K(x) 的可计算上界，可能很松；对随机串最大，更接近熵而非复杂度。第 3 课
置换不变permutation invariance任意打乱各格位置后值不变。单格熵 H 具有此性质，所以看不见空间结构。第 3 课
期望的线性性linearity of expectationE[X+Y] = E[X] + E[Y]，不要求独立。用于证明随机行 E[T] = (N−1)/2。第 3 课
不可压缩性（计数论证）incompressibility (counting argument)长度 n 的串中，能被任一固定无损压缩器压到少于 n − k 位的，占比小于 2⁻ᵏ。第 3 课
Kolmogorov 复杂度Kolmogorov complexity K(x)在固定的通用语言里输出 x 并停机的最短程序长度。K(x) ≤ |x| + c；不可计算，压缩长度只给出上界。第 4 课
不变性定理invariance theorem换一种通用语言，K(x) 最多变化一个与 x 无关的常数（即解释器的长度）。第 4 课
不可压缩串incompressible stringK(x) ≥ |x| 的串，是「随机」的算法定义。长度为 n 的串中，K(x) < n − k 的不到 2⁻ᵏ。第 4 课
两段式描述two-part description先描述集合 S（模型），再给出 x 在 S 里的下标（约 log₂|S| 位）。第 4 课
sophisticationSoph(x)在所有满足 x ∈ S 且 K(x|S) ≥ log₂|S| − c 的集合 S 中，K(S) 的最小值（Aaronson 博客版）。简单串和随机串都低。2014 年咖啡论文用的是 Koppel 的变体，多一个条件 K(S) + log₂|S| ≤ K(x) + c。第 4 课
资源受限 Kolmogorov 复杂度resource-bounded Kolmogorov complexity, Kᵀ(x)在时间 T(n) 内输出 x 的最短程序长度；总有 Kᵀ(x) ≥ K(x)。确定性系统「初态 + 规则 + t」的短描述要跑约 t 步，会被时间上界排除。第 5 课
complextropycomplextropy（Aaronson 2011 的用词）在 n log n 时间内、能输出集合 S 上近似均匀样本的最短程序的长度。要求 x ∈ S，并且任何 n log n 时间、可以向 S 要样本的程序，输出 x 都至少需要 log₂|S| − c 位。采样器和重构器两处都必须加效率约束。第 5 课
自定界编码self-delimiting code读者能自己判断在哪里结束的编码。例如先把 t 的位数 ℓ 每位写两遍，加分隔符 01，再写 t，总长 log₂ t + O(log log t)。第 5 课
表观复杂度apparent complexityK(f(x))，f 是粗粒化或平滑函数。实验中用粗粒化分档后数组的 gzip 字节数估计；细粒度数组的 gzip 字节数则估计熵。相当于把 sophistication 的模型固定为 Sf,x = {y : f(y) = f(x)}。第 5 课（第 7 课实操）
拉普拉斯算子 / 五点核Laplacian, 5-point stencil（Laplacian 卷積）∇²u 的离散近似 Lu = 上+下+左+右−4·中，对应核 [[0,1,0],[1,−4,1],[0,1,0]]；误差 O(h²)。第 6 课
显式欧拉格式explicit Euler（顯式歐拉）u ← u + r·Lu，r = DΔt/h²（notebook 的 diffusion_rate）。二维稳定条件 r ≤ 1/4。第 6 课
最大值原理maximum principler ≤ 1/4 时新值是五个旧值的凸组合，不会超出它们的最小值和最大值。第 6 课
von Neumann 稳定性分析von Neumann analysis代入单频波求每步放大倍数 g = 1 − 4r[sin²(α/2)+sin²(β/2)]；棋盘格模态 g = 1−8r 最先失控。第 6 课
零通量边界Neumann / zero-flux boundary穿过边界的通量为零；replicate 填充是它的离散版本，保证总量守恒。第 6 课
互相关cross-correlation核不翻转、直接对齐相乘求和；PyTorch 的 conv2d 实际算的是它。对称核时与卷积相同。第 6 课
(N, C, H, W)F.conv2d 输入布局批大小、通道、高、宽；核为 (输出通道, 输入通道, kH, kW)。unsqueeze(0) 在最前面补长度为 1 的维。第 6 课
粗粒化coarse-graining每格换成以它为中心的 g×g 窗口平均，窗口出界部分不计入（avg_pool2d(..., count_include_pad=False)），再分成少数几档。用来抹掉随机细节。第 7 课
交互 / 非交互咖啡自动机interacting / non-interacting coffee automaton交互：每步交换一对相邻且不同的格子，一格一个粒子。非交互：每个奶油粒子独立随机游走，可叠加。第 7 课
分档伪影thresholding artifact平滑渐变恰好落在档位分界时，微小噪声让格子在两档间跳动，被压缩器误计为结构。论文用七档 + 按行多数 ±1 调整修正。第 7 课
