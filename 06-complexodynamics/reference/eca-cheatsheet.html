初等元胞自动机

规则号 ↔ 规则表 ↔ 布尔式 ↔ PyTorch。来自 第 1 课。

编码

k = 4l + 2c + r　　new = (n >> k) & 1

邻域从 111（k=7）排到 000（k=0）时，输出那一列从左往右读就是规则号的二进制NKS p.53。

l c r111110101100011010001000布尔式
Rule 3000011110l ⊕ (c ∨ r)
Rule 9001011010l ⊕ r

Rule 30 布尔式的证明（两种情况）

  • c ∨ r = 0（100, 000）：新状态等于 l，而 l ⊕ 0 = l。
  • c ∨ r = 1（其余 6 种）：新状态等于 ¬l，而 l ⊕ 1 = ¬l。

口诀：中间和右边都空，就抄左邻居；只要有一个不空，就把左邻居取反。

PyTorch

left   = torch.roll(x,  1)   # left[i]  = x[i-1]，周期边界
right  = torch.roll(x, -1)   # right[i] = x[i+1]
x_next = left ^ (x | right)  # Rule 30，整行逐元素运算

def make_rule(n):            # 任意 0–255 规则
    table = torch.tensor([(n >> k) & 1 for k in range(8)])
    return lambda l, c, r: table[4*l + 2*c + r]   # 高级索引查表
易错点正确理解
roll(x, 1) 是「右移」，所以是右邻居？内容右移以后，第 i 位放的是 x[i−1]，所以是左邻居。
边界补 0？roll 是循环移位，边界是周期的。咖啡扩散用的才是 replicate。
