第 6 课 · 复杂动力学第一定律

一个 3×3 的核，就是扩散方程

从 Taylor 展开推出五点拉普拉斯，再看 F.conv2d 怎样一次更新整张网格，以及奶油为什么一滴不少

notebook 第 3 节把咖啡杯换成了一张 50×50 的网格：中间 10×10 的方块是奶油（浓度 1），其余是咖啡（浓度 0）。每一步，奶油向四周散开一点。Aaronson 用咖啡杯讲「复杂度先升后降」：刚倒进去时界限分明，最后混得均匀，都很简单，中间那些卷须状的图案才复杂[4]。要测这个过程，先得有这个过程。notebook 的实现只有几行：

kernel = torch.tensor(
    [[0, 1, 0], [1, -4, 1], [0, 1, 0]],
    dtype=torch.float32,
).unsqueeze(0).unsqueeze(0)
...
for _ in range(steps):
    padded = F.pad(current, (1, 1, 1, 1), mode="replicate")
    laplacian = F.conv2d(padded, kernel)
    current = torch.clamp(current + diffusion_rate * laplacian, 0, 1)

本课收获：你能从扩散方程推出这个 3×3 核和更新式，证明 r ≤ 1/4 时格式稳定，并证明 replicate 边界下奶油总量严格守恒。你还能说清 conv2d 每一步的张量形状，并用 torch.roll 写出同一个拉普拉斯的周期边界版本。

1　从扩散方程到五点核

浓度 u(x, y, t) 的扩散方程是 ∂u/∂t = D ∇²u，其中 ∇²u = ∂²u/∂x² + ∂²u/∂y²，D 是扩散系数[1]。直观上，∇²u 衡量「这一点比周围平均值低多少」：比邻居低就流进来，比邻居高就流出去。

网格上没有导数，只有格点值。设格距为 h，记 uᵢ = u(x + ih)。先在一维推导二阶导数的近似：

Taylor 展开。在 x 处展开到四阶：

u(x ± h) = u ± h u′ + (h²/2) u″ ± (h³/6) u‴ + O(h⁴)

两式相加。奇数阶项正负抵消：u(x+h) + u(x−h) = 2u + h² u″ + O(h⁴)。

移项除以 h²。

(uᵢ₊₁ − 2uᵢ + uᵢ₋₁) ⁄ h² = u″(x) + O(h²)

这就是二阶中心差分，误差随 h² 缩小，所以叫二阶精度。∎

二维时，x 方向和 y 方向各用一次，再相加：

∇²u ≈ (上 + 下 + 左 + 右 − 4·中) ⁄ h²

把每个格点的系数按位置摆好，就是 notebook 的核：

记 Lu = 上 + 下 + 左 + 右 − 4·中（不除以 h²）。时间方向用最简单的显式欧拉法：uⁿ⁺¹ = uⁿ + Δt · D ∇²uⁿ。代入上式：

u ← u + r · Lu，　其中 r = D Δt ⁄ h²

notebook 的 diffusion_rate 就是这个 r，一个没有量纲的数。D、Δt、h 三者只通过 r 起作用。

2　F.conv2d：一次算出整张网格的 Lu

第 1 课用 torch.roll 一次拿到所有格子的邻居。这里换了个工具：卷积。F.conv2d 把 3×3 的核在网格上滑动，每到一个位置，就把核与覆盖的 9 个值逐个相乘再求和[2]。用上面的核，算出来正好是那一格的 Lu。

严格说，PyTorch 的卷积层算的是互相关：核不翻转，直接对齐相乘[2]。数学里的卷积要先把核旋转 180°。这个核上下左右都对称，翻不翻转结果都一样，所以这里不用操心。

形状是最容易出错的地方。F.conv2d 要求输入是四维的 (N, C, H, W)：批大小、通道数、高、宽；核是 (输出通道, 输入通道, kH, kW)[2]。逐行看：

代码形状说明
grid(50, 50)一张网格
.unsqueeze(0).unsqueeze(0)(1, 1, 50, 50)在最前面补两个长度为 1 的维：N = 1，C = 1
kernel（两次 unsqueeze 后）(1, 1, 3, 3)1 个输出通道，1 个输入通道
F.pad(current, (1,1,1,1), mode="replicate")(1, 1, 52, 52)四周各补一圈

F.pad 的填充元组从最后一维往前写：(左, 右, 上, 下)，前两个数管宽度 W，后两个管高度 H[3]。mode="replicate" 用最近的边缘值来填，例如第 0 行的「上邻居」就是它自己。第 1 课测验第 5 题提到过它，下面第 4 节会看到这个选择的物理意义。

3　稳定性：为什么 r 不能超过 1/4

把更新式按格点重新整理：

u′ = (1 − 4r)·中 + r·(上 + 下 + 左 + 右)

最大值原理。五个系数之和是 (1 − 4r) + 4r = 1。若 0 ≤ r ≤ 1/4，五个系数都非负，u′ 就是五个值的凸组合（加权平均），所以

min(五个值) ≤ u′ ≤ max(五个值)

对每一步、每一格都成立。初值都在 [0, 1] 里，以后就永远在 [0, 1] 里。∎

这条证明有一个直接推论：notebook 用 r = 0.2 ≤ 1/4，所以 torch.clamp(…, 0, 1) 从来不会被触发。我用纯 Python 按 notebook 的设置跑了 50 步，被截断的格子数是 0。r = 0.25 时也是 0。

r > 1/4 时，中心系数 1 − 4r 变成负数，凸组合的论证就失效了。哪种图案最先出问题？用 von Neumann 分析：代入单一频率的波 uⱼₖ = gⁿ e^{i(αj + βk)}，每一步的放大倍数是[1]

g(α, β) = 1 − 4r·[sin²(α/2) + sin²(β/2)]

最坏的情况是 α = β = π，也就是相邻格子正负交替的棋盘格，这时 g = 1 − 8r。要求 |g| ≤ 1，就得 r ≤ 1/4，与凸组合的结论一致。r = 0.3 时 g = −1.4：棋盘格成分每步放大 1.4 倍，还每步变号。

按 notebook 的设置、不加 clamp 实测：r = 0.3 时第 6 步开始出现明显越界（超出 [0, 1] 超过 0.001），第 50 步最大值约 3.2 万、最小值约 −3.1 万。r = 0.26 时要到第 46 步才看得出来，因为 g = −1.08，增长很慢。

4　奶油一滴不少：replicate 边界下的守恒

上一节练习的第 ① 步里，总量一直是 64。这不是巧合。先看一维：设网格有 n 格，下标 0 到 n−1，replicate 补出的两个虚格是 u₋₁ = u₀、uₙ = uₙ₋₁。

拆成通量差。uᵢ₊₁ − 2uᵢ + uᵢ₋₁ = (uᵢ₊₁ − uᵢ) − (uᵢ − uᵢ₋₁)。记 Fᵢ = uᵢ₊₁ − uᵢ，它正比于从格 i+1 流进格 i 的量。

求和裂项。Σᵢ₌₀ⁿ⁻¹ (Fᵢ − Fᵢ₋₁) = Fₙ₋₁ − F₋₁ = (uₙ − uₙ₋₁) − (u₀ − u₋₁)，中间的项全部抵消。

代入边界。replicate 让两个括号都等于 0。所以 Σ Lu = 0，Σ u′ = Σ u + r·Σ Lu = Σ u。

二维。五点 Lu 是 x 方向和 y 方向两个一维差分之和，每一行、每一列分别裂项，各自为 0。∎

Fₙ₋₁ = 0 的意思是穿过边界的通量为零：杯壁不让奶油流出去，也不让咖啡流进来。这就是物理上的零通量边界（Neumann 边界条件）。replicate 填充正是它的离散版本。

两个结论合起来：r ≤ 1/4 时 clamp 不起作用（第 3 节），replicate 让 Σ Lu = 0（本节），所以 notebook 的扩散严格守恒。我用 float64 的纯 Python 按 notebook 的设置跑 50 步，总量始终是 100，最大偏差 1.4 × 10⁻¹⁴。torch 用 float32，求和会有更大的舍入误差，但仍然是舍入级别。如果把 r 调到 0.3，clamp 开始起作用，同样的设置下第 50 步总量会变成约 779。

一直跑下去，浓度会趋于均匀，等于 100 ⁄ 2500 = 0.04。跑到第 1000 步时，最低和最高浓度分别是 0.0339 和 0.0466。中间几个时刻的最高浓度是：t = 10 时 0.9727，t = 25 时 0.7783，t = 50 时 0.5378。

换成周期边界会怎样

第 1 课的 torch.roll 是周期边界，网格首尾相接。用它也能写同一个拉普拉斯，裂项时边界项变成 Fₙ₋₁ − F₋₁ = (u₀ − uₙ₋₁) − (u₀ − uₙ₋₁) = 0，所以周期边界下也守恒。两种边界只有在奶油碰到网格边缘后才会给出不同结果。notebook 的方块离边缘有 20 格，跑到第 50 步时边缘的浓度才约 5.7 × 10⁻⁶。所以两种边界在这 50 步内的结果几乎一样：我比较过，最大差别约 10⁻²¹。

5　回想测验

凭记忆作答，先别往上翻。

1. 中心差分 (uᵢ₊₁ − 2uᵢ + uᵢ₋₁)/h² 近似 u″ 的误差是多少阶？

  1. O(h)
  2. O(1)
  3. O(h²)
  4. O(h⁴)

两个 Taylor 展开相加后，奇数阶项抵消，剩下的余项是 O(h⁴)，除以 h² 后是 O(h²)。

2. 二维显式扩散格式 u ← u + r·Lu 的稳定条件是？

  1. r ≤ 1/4
  2. r ≤ 1/2
  3. r ≤ 1
  4. 任意 r 都稳定

中心系数 1 − 4r ≥ 0 才是凸组合；von Neumann 分析中棋盘格模态的 g = 1 − 8r，|g| ≤ 1 也给出 r ≤ 1/4。一维时是 r ≤ 1/2。

3. 形状为 (1, 1, 50, 50) 的张量，先 F.pad(x, (1,1,1,1)) 再与 (1, 1, 3, 3) 的核做 F.conv2d，输出形状是？

  1. (1, 1, 52, 52)
  2. (1, 1, 48, 48)
  3. (50, 50)
  4. (1, 1, 50, 50)

pad 后是 52×52，3×3 的核不补零滑动，得到 52 − 3 + 1 = 50。前两维不变。

4. notebook 的扩散为什么能严格守恒奶油总量？

  1. 因为 clamp 把浓度限制在 [0, 1]
  2. replicate 让边界通量为零，且 r = 0.2 ≤ 1/4 使 clamp 不起作用
  3. 因为拉普拉斯核的中心是 −4
  4. 因为卷积不翻转核

clamp 反而是唯一可能破坏守恒的环节。核的系数和为 0 只说明「常数场不变」，守恒还要靠边界项裂项为零。

5. r 略大于 1/4 时，最先失控的是哪种图案？

  1. 整体均匀的常数
  2. 一个缓慢变化的大斑块
  3. 相邻格子正负交替的棋盘格
  4. 只沿 x 方向变化的条纹

α = β = π 时 sin² 项都取最大值 1，g = 1 − 8r 的绝对值最大。只沿 x 方向的最高频条纹 g = 1 − 4r，要到 r > 1/2 才失控。

6　编程练习

练习 C：用 torch.roll 写周期边界拉普拉斯，再验证守恒

写一个 laplacian_periodic(u)：输入形状 (H, W)，返回同形状的 Lu，边界是周期的。不用 conv2d，也不写循环。然后用两个 assert 验收：一个检查它与 conv2d 加 mode="circular" 填充的结果一致，另一个检查 notebook 扩散的每一步总量都是 100。

提示：第 1 课讲过 torch.roll(x, 1)[i] = x[i − 1]。二维时加上 dims=0 沿行滚动，dims=1 沿列滚动。

验收：

kernel = torch.tensor([[0., 1., 0.], [1., -4., 1.], [0., 1., 0.]])[None, None]   # (1, 1, 3, 3)
x = torch.rand(50, 50)
ref = F.conv2d(F.pad(x[None, None], (1, 1, 1, 1), mode="circular"), kernel)[0, 0]
assert torch.allclose(laplacian_periodic(x), ref, atol=1e-5)

coffee = torch.zeros(50, 50)
coffee[20:30, 20:30] = 1.0
h = diffusion_2d(coffee, steps=50, diffusion_rate=0.2)
assert h.shape == (51, 50, 50)
assert torch.allclose(h.sum(dim=(1, 2)), torch.full((51,), 100.0), atol=1e-2)
print(diffusion_2d(coffee, steps=50, diffusion_rate=0.3)[-1].sum())   # 远大于 100：clamp 破坏了守恒
参考解答（写完再看） 
def laplacian_periodic(u: torch.Tensor) -> torch.Tensor:
    return (torch.roll(u, 1, dims=0) + torch.roll(u, -1, dims=0)      # 上、下邻居
            + torch.roll(u, 1, dims=1) + torch.roll(u, -1, dims=1)    # 左、右邻居
            - 4 * u)

x[None, None] 和 x.unsqueeze(0).unsqueeze(0) 等价，都在最前面插入两个长度为 1 的维。h.sum(dim=(1, 2)) 同时沿高和宽求和，把 (51, 50, 50) 归约成 (51,)，也就是每一步一个总量。第 2 课讲过：沿哪一维运算，那一维就被消掉，这里一次消掉了两维。

atol 设成 1e-2 而不是 1e-6，是因为 float32 把 2500 个数加起来会有舍入误差。守恒是在精确算术下证明的，浮点运算只能做到近似。
