复杂动力学第一定律

熵一直增加。有结构的图案却先出现，再消失。这一包用七课把这句话从一条规则推到一杯咖啡。

Aaronson 在 2011 年问：封闭系统里熵只增不减，为什么「有趣」会先升后降。胡嘉玺 notebook 第 1 章用 Rule 30 和奶油扩散把这个问题做成了可以跑的代码。这一包顺着那份 notebook，也顺着他和 Carroll、Ouellette 在 2014 年做的咖啡自动机实验。

假定你会 Python，PyTorch 从张量 API 讲起。每课只多一个工具，下一课会用到它。按编号往下读，做完该课的练习再进下一课。

七课一条线

先把系统生成出来，再发现两种常用度量量不准，然后去定义「复杂」到底是什么，最后用一个能跑的实验检验那句话。

  1. 从数字 30 到一行 PyTorch 规则号怎样变成规则表，torch.roll 怎样一次更新整行。
  2. Shannon 熵：为什么最多 1 bit 从平均惊讶度推出二元熵的最大值，再读懂 measure_entropy。
  3. 度量的陷阱：同一张图，三种读数 转换次数、单格熵、压缩长度各自看见什么，notebook 的「先升后降」从哪来。
  4. 最短程序，与程序里不随机的那一半 Kolmogorov 复杂度为什么量不出「有趣」，sophistication 怎样拆开模型和噪声。
  5. Complextropy：为什么必须加资源限制 一段只有 log t 位的描述怎样让前两个定义失效，以及程序必须跑得快。
  6. 一个 3×3 的核，就是扩散方程 五点拉普拉斯怎样从 Taylor 展开里出来，conv2d 怎样搬奶油。
  7. 咖啡自动机：让复杂度先升后降 粗粒化再压缩，复现 2014 年的实验，并拿它检验 notebook 的连续扩散。
