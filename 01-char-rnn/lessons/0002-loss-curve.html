第 2 课 · RNN 的不合理有效性

那条漂亮的损失曲线是假的

从 ln V 和指数平滑推出 80 的来历，再找到被它盖住的回弹

Notebook 第 4 节画的损失曲线从约 80 平滑地降到约 5，看上去训练得很好。可是 24 个字符的词表，瞎猜的损失也才约 3.18。这个 80 从哪来？

本课收获：你能算出一个没学过的模型损失应该是多少，用公式拆开 notebook 的曲线，并知道看训练曲线时先核对哪几件事。这也回答了 notebook 的思考题 4。

1　起点应该是多少

单步交叉熵是 −ln p(正确字符)。一个什么都没学的模型对 V 个字符一视同仁，p = 1/V，所以：

初始损失 ≈ −ln(1/V) = ln V

这是每次训练都该做的第一项检查。起点对不上，通常就是哪里算错了。

2　两种尺度混在了一起

对照 Karpathy 的 min-char-rnn 和 notebook[2]：

# min-char-rnn：loss 是 25 步的总和
loss += -np.log(ps[t][targets[t],0])
smooth_loss = -np.log(1.0/vocab_size)*seq_length   # 初值也是总和，正确

# notebook：初值抄了过来，loss 却变成平均
criterion = nn.CrossEntropyLoss()                  # 默认 reduction='mean'
smooth_loss = -np.log(1.0 / vocab_size) * seq_length
smooth_loss = smooth_loss * 0.999 + loss.item() * 0.001

nn.CrossEntropyLoss 默认取平均[3]。于是平滑值的初值是 79.45，每步混入的却是约 3 的数。曲线下降的主要是这个错误初值在慢慢衰减。

展开递推。令 s_n = β s_{n−1} + (1 − β) l_n，β = 0.999。反复代入得

s_n = βⁿ s₀ + (1 − β) Σ_{i=1..n} β^{n−i} l_i

两条曲线相减。同一串真实损失 l，用两个不同的初值 s₀ 和 s₀′ 平滑，第二项完全相同，所以

s_n − s_n′ = βⁿ (s₀ − s₀′)

初值的差只按 βⁿ 衰减，和模型学得好不好毫无关系。∎

代入 n = 3000：0.999³⁰⁰⁰ ≈ 0.0497，s₀ − s₀′ = 79.45 − 3.18 = 76.27，差值应该是 3.79。我实测 notebook 曲线的终点是 4.92，初值改成 ln V 后的终点是 1.13，差值正好 3.79。

3　被盖住的东西

下面是实测数据。先看 notebook 的曲线（红）和真实损失（贴在底部的黑线），再点「换成真实损失」，纵轴会放大。

lr = 0.01 时，真实损失在约 800 步从 0.18 跳回 2.3，之后再也回不去：最后 500 步平均 0.71。红线对这一切几乎没有反应。这就是上一课最后说的回弹。训练结束时，这个模型读到 hell 预测的是空格，不是 o。

回弹的原因是学习率

我用不同学习率各跑了 3 个种子，再关掉梯度裁剪各跑 3 个，每次 3000 步：

设置回弹（200 步均值跳升超过 1）最后 500 步平均损失
lr = 0.01（notebook）2 / 30.71、0.85、1.03
lr = 0.01，不裁剪2 / 31.13、1.23、1.57
lr = 0.0030 / 30.006、0.007、0.007
lr = 0.0010 / 30.033、0.024、0.059

学习率降到 0.003，损失比原来低了约 100 倍。这里有三点要读准：

  • 梯度裁剪没有阻止回弹。思考题 4 问它如何防止不稳定。它做的事很简单：若梯度总范数 ‖g‖ 超过 c，就把 g 缩放成 g · c / ‖g‖，方向不变[4]。它限制单步冲击，确实略有帮助（不裁剪时损失更高），但学习率太大时救不回来。lr = 0.01 时，3000 步里有 423 到 436 步触发了裁剪；lr = 0.003 时只有 23 到 35 步。
  • 同一个种子，不同机器回弹时间不同。种子 42 在我的 Mac 上要到 1000 步之后才回弹，在 DGX Spark 上约 800 步。所以别只看某一次的时间点，要看统计。
  • 回弹之后为什么回不来，我只有相关证据。回弹后，|h| > 0.99 的单元比例从约 0.4 升到 0.89，而 lr = 0.003 时最后只有 0.18。下面的导数说明了为什么这很可能有害，但我没有做实验把它单独分离出来。

def ema(raw, init, beta=0.999):
    out, s = [], init
    for l in raw:
        s = beta * s + (1 - beta) * l
        out.append(s)
    return out

这份解答我跑过。注意打印结果：模型完全没学，曲线也会一路下降。
