第 3 课 · RNN 的不合理有效性

截断 BPTT：一行 detach 决定它能记多远

状态一直往前传，梯度只回传 25 步。这两件事的差别，就是 RNN 记忆的边界

Notebook 的训练循环里，有一行很容易被当成样板代码：

h = h.detach()                  # 分離隱藏狀態（截斷 BPTT）
outputs, _, h = model(inputs, h)

本课收获：你能说清这行删掉会怎样，推导梯度为什么随距离衰减，并能用实验结果预测：窗口长度决定模型能学会多远的依赖。

1　数据怎么切

get_batch 把文本切成长 25 的块，目标是输入右移一位。下一块从上一块的终点接着走，所以一块的最后一个隐藏状态，正好是下一块的起点。

inputs  = data[start     : start + 25]
targets = data[start + 1 : start + 26]
# 下一轮 start += 25

2　detach 切断的是梯度，不是状态

h.detach() 返回一个数值相同、但和计算图断开的张量。所以：

前向：h 的数值反向：梯度
块内传递回传
跨块（detach）传递不回传
跨块（每块清零）不传递不回传

删掉这一行会怎样？第二次 backward() 要穿过第一块的计算图，而那张图已经被释放了。我实际跑出来的错误是：

RuntimeError: Trying to backward through the graph a second time ...

即使保留计算图不报错，图也会随文本一直变长，内存和时间都撑不住。Karpathy 的实验也是这样截断的，他用的长度是 100 个字符[1, Paul Graham generator]。

状态跨块传递有没有用？我用 lr = 0.003 跑了同样的 3000 步，只改一处：

跨块时最后 500 步平均损失
h.detach()（notebook 的做法）0.006
每块把 h 清零0.225

只跑了一个种子，但差了约 37 倍。清零后，每块开头的字符完全没有上下文，这部分损失怎么也降不下来。

3　推导：梯度为什么随距离衰减

一步。记 h_t = tanh(z_t)，z_t = W_xh x_t + W_hh h_{t−1} + b_h。由链式法则，

∂h_t / ∂h_{t−1} = D_t W_hh，　D_t = diag(1 − h_t²)

k 步。连乘：

∂h_t / ∂h_{t−k} = D_t W_hh · D_{t−1} W_hh ⋯ D_{t−k+1} W_hh

上界。矩阵范数满足次乘性，又有 ‖D‖ ≤ 1，所以

‖∂h_t / ∂h_{t−k}‖ ≤ ‖W_hh‖ᵏ

若 W_hh 的最大奇异值小于 1，这个界随 k 指数趋于 0。这就是梯度消失的充分条件[2]。∎

反过来，范数大于 1 时连乘可能爆炸，这才需要第 2 课的梯度裁剪。注意上界只说明小于 1 时一定消失；大于 1 时只是有可能爆炸[2]。

练习 B：连乘有多快

简化成标量，每步乘 0.9。已知 0.9¹⁰ ≈ 0.349，回传 20 步后还剩多少？

第 2 课的饱和也算进来：若单元值约 0.99，那一步的 D 约 0.02。这对连乘意味着每过一步大约剩下原来的几分之几？（填小数）

4　窗口决定能学多远

我造了一个专门测记忆的任务。文本由这样的片段组成：一个随机字母（a 或 b），k 个横线，再重复一次那个字母。例如 k = 3 时是 a---a b---b，这里为了看清加了空格。要预测对最后的字母，模型必须记住 k 步以前的东西。

H = 64，总共读 30 万字符，lr = 0.002，每种设置跑 3 个种子，下面是预测最后字母的准确率（瞎猜是 0.5）：

距离 k窗口 5窗口 25窗口 100
31.00、1.00、1.001.00、1.00、1.001.00、1.00、1.00
100.47、0.40、0.481.00、1.00、0.521.00、0.93、1.00
200.00、0.00、0.000.00、0.00、0.000.91、0.99、0.00

准确率 0.00 不是比瞎猜还差：模型根本没学会那个位置要结束，一直预测横线。规律很清楚：距离短于窗口才可能学会。但这不是一道硬边界，k = 20、窗口 25 也全部失败，k = 10、窗口 25 还有一次失败，因为窗口够长只是必要条件，第 3 节的衰减还在起作用。这里三种窗口读的字符数相同，更新次数相差 20 倍，所以窗口 100 的结果也包含了这个因素。

这也解释了下一篇论文的动机：要记得更远，光拉长窗口不够，得改变连乘本身，这就是 LSTM 要做的事[1, Getting fancy]。

h.detach() 之后，下一块开始时 h 的数值如何？

  1. 全部清零重来
  2. 随机重新生成

detach 只断开计算图，不改数值。所以状态能跨块，梯度不能。

窗口 25 的模型，依赖距离 20 也可能学不会。最直接的原因是什么？

  1. 权重共享失效了
  2. 长距离梯度太小
  3. 词表大小不够了
  4. 状态不能传过去

窗口内的梯度仍要连乘衰减。窗口够长是必要条件，不是充分条件。
