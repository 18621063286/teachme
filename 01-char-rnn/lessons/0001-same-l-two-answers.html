第 1 课 · RNN 的不合理有效性

同一个 l，两个答案

从 "hello" 这个最小的例子，证明 RNN 为什么离不开 W_hh

训练串是 "hello"。模型每次看一个字符，要猜下一个。读到第一个 l，正确答案是 l；读到第二个 l，正确答案是 o。两次输入完全相同，答案却不同。Karpathy 说，RNN 因此不能只靠输入，必须用循环连接记住上下文[1, Character-Level Language Models]。

这节课把这句话变成一个可以计算的结论。

本课收获：你能写出更新公式和每个矩阵的形状，能证明没有 W_hh 时 "hello" 的平均损失最低只能到 0.3466，并能用 PyTorch 写出一步 RNN。

1　公式和形状

Notebook 第 2.1 节写的是[2]：

h_t = tanh(W_xh x_t + W_hh h_{t−1} + b_h)

y_t = W_hy h_t + b_y

  • W_xh x_t 把当前字符写进状态。
  • W_hh h_{t−1} 把旧状态带到这一步。
  • tanh 把相加的结果逐元素压到 (−1, 1)[1, RNN computation]。
  • y_t 是每个字符的分数，经过 softmax 变成概率。

Karpathy 的版本没有两个偏置 b，其余相同[1, RNN computation]。形状可以从矩阵乘法倒推：结果要是 H 维，输入是 V 维，矩阵就得是 H×V。

3　推导：没有 W_hh 最好能做到多少

上面的演示还不算证明：切断后的权重是带着记忆训练出来的，重新训练也许能补救。下面证明不能。

第一步，状态退化。令 W_hh = 0，公式变成 h_t = tanh(W_xh x_t + b_h)。h_t 只取决于 x_t，所以两个 l 得到同一个 h，也就得到同一个概率分布。无论权重怎么取，都是如此。

第二步，写出损失。单步损失是交叉熵 −ln p(正确字符)[3]。设读到 l 时预测 l 的概率是 a，预测 o 的概率是 b，a + b ≤ 1。两个 l 这两步的损失之和是

L(a, b) = −ln a − ln b

第三步，求最小值。L 随 a、b 增大而减小，所以最优时 a + b = 1。令 b = 1 − a，求导：

dL/da = −1/a + 1/(1 − a) = 0　⇒　a = 1/2

二阶导 1/a² + 1/(1 − a)² 恒为正，这确实是最小值，为 2 ln 2。∎

h→e 和 e→l 这两步，输入各不相同，损失可以逼近 0。所以这 4 步的平均损失有一个下界。

练习 C：下界是多少

用 ln 2 ≈ 0.693，算没有 W_hh 时 "hello" 4 步的最低平均损失。

我用 torch 把两种情况都训练了 400 步（同样的初始化方式和优化器，Adam，学习率 0.05），实测结果和推导相符：

模型最终平均损失两个 l 上的预测
有 W_hh0.0005第一个 l 预测 l，第二个 l 预测 o，都接近 1
W_hh 固定为 00.3473（下界 0.3466）两个 l 都是 l 0.5、o 0.5

记忆也能追溯到更早的字符。把公式展开两层（省略偏置）就能看到：

h₂ = tanh(W_xh x₂ + W_hh · tanh(W_xh x₁ + W_hh h₀))

每多一步就多包一层，所以 h_t 依赖所有更早的输入，而且只通过 W_hh 这条路依赖。

4　写成 PyTorch

对照 notebook 的 VanillaRNN.forward，本课只需要这几个 API：

  • torch.mm(A, B)：矩阵乘法，两个参数都必须是 2 维张量[4]。所以 notebook 把向量写成 (H, 1) 的列向量，而不是 (H,)。
  • x[idx] = 1.0：x 的形状是 (V, 1)，这行把第 idx 行设为 1，也就是 one-hot。
  • torch.tanh(t)：逐元素计算，形状不变[5]。
  • nn.Parameter(t)：把张量注册成模型参数，优化器才能更新它[6]。下面的练习不训练，所以用普通张量。

def step(idx, h, W_hh=W_hh):
    x = torch.zeros(V, 1)
    x[idx] = 1.0
    h = torch.tanh(torch.mm(W_xh, x) + torch.mm(W_hh, h) + b_h)
    y = torch.mm(W_hy, h) + b_y
    return h, y

5　不看上文，回答

W_hh 为 0 时，第二个 l 的 h 和第一个 l 的 h 相比如何？

  1. 符号整体相反
  2. 全部变成零值
  3. 大小略有差异
  4. 两者完全相同

h_t = tanh(W_xh x_t + b_h) 只取决于当前字符，权重取什么值都一样。

W_xh 乘以一个 one-hot 向量，得到的是什么？

  1. 某一行向量
  2. 某一列向量
  3. 对角线向量
  4. 各行平均值

one-hot 只有第 idx 个位置是 1，矩阵乘法就只留下第 idx 列。W_xh 是 H×V，所以结果是 H 维。

读 5 个字符和读 5000 个字符，RNN 的参数量有什么区别？

  1. 与序列长度成正比
  2. 与序列长度成反比
  3. 与序列长度无关系
  4. 与长度平方成正比

每一步共用同一组 W 和 b，序列长度只决定循环次数。
