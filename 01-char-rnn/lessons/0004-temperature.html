第 4 课 · RNN 的不合理有效性

采样与温度：一个除号做了什么

推导 softmax(y/T)，再看模型到底是在写作还是在背书

训练好以后，生成文本只有一个循环：算出下一个字符的概率，抽一个，把它喂回去[1, Character-Level Language Models]。Notebook 的 sample 里，温度只出现在一处：

probs = F.softmax(y.squeeze() / temperature, dim=0)
idx = torch.multinomial(probs, 1).item()

本课收获：你能证明温度升高时分布的熵一定不减，说清 T → 0 和 T → ∞ 的极限，并能判断一段「写得很好」的输出是不是只是背诵。这也回答了 notebook 的思考题 5。

1　推导

分数 y 除以 T 再做 softmax：

p_i(T) = exp(y_i / T) / Σ_j exp(y_j / T)

分母在两两相比时会约掉，于是任意两个字符的概率比是：

p_i(T) / p_j(T) = exp((y_i − y_j) / T) = [ p_i(1) / p_j(1) ]^(1/T)

这条式子就够看出两个极限。设 y_i > y_j：

  • T → 0：指数趋于 +∞，比值发散，最高分的字符概率趋于 1（并列时平分）。采样退化成每次取最大值。
  • T → ∞：指数趋于 0，所有比值趋于 1，分布趋于均匀，模型学到的东西全部作废。

Karpathy 说降温让模型「更自信也更保守」，升温「更多样但错误更多」[1, Temperature]。「多样」可以用熵来量，下面证明它随 T 单调不减。

设定。令 β = 1/T，Z = Σ exp(βy_j)，于是 ln p_i = βy_i − ln Z。记 ȳ = Σ p_i y_i。

求 dp/dβ。先有 d(ln Z)/dβ = ȳ，所以 dp_i/dβ = p_i (y_i − ȳ)。

求 dH/dβ。对 H = −Σ p_i ln p_i 求导，并利用 Σ dp_i/dβ = 0：

dH/dβ = −Σ (dp_i/dβ) ln p_i = −Σ p_i (y_i − ȳ)(βy_i − ln Z)

常数项 ln Z 乘以 Σ p_i (y_i − ȳ) = 0 后消失，剩下 dH/dβ = −β Var(y)，其中 Var 按 p 加权。

换回 T。dβ/dT = −1/T²，所以

dH/dT = Var(y) / T³ ≥ 0

只有所有分数都相等时才取等号。∎

熵是沿 438 字符训练文本逐步计算后取平均，24 个字符的上限是 log₂24 ≈ 4.585。词有效率只算词在不在词表里，不看语序。

两列熵都随 T 上升，和证明相符。再看两个模型的输出。T 接近 0 时（我用 0.001），生成结果是：

lr=0.01 ：atal networks networks\nnetworks\nnetworks\nnetworks\nnetworks...
lr=0.003：ata\ndrives learning\nlearning from examples\nexamples help networks\n...

第一行陷入了循环。Karpathy 在 Paul Graham 数据上观察到同样的现象，他的模型在低温下反复说同一句关于创业的话[1, Temperature]。第二行看上去好多了，但除了开头那个 ata，后面逐句一比都是训练文本。

别被第二行骗了。这份训练数据是 18 句话重复 20 遍，没有划分验证集。lr = 0.003 的模型最后损失约 0.006，意思是它几乎把这 438 个字符背了下来。所以这里的「词有效率 99.6%」说明不了泛化能力。Karpathy 用的数据从约 1MB 到 100MB[1]，这篇文章说的「不合理的有效性」是在那种规模上观察到的。Notebook 这个玩具数据展示不了这一点。

3　不看上文，回答

T 从 1 降到 0.5，两个字符的概率比会怎样变化？

  1. 比值保持不变
  2. 比值开平方根
  3. 比值变成平方
  4. 比值变成倒数

比值的指数是 1/T。T = 0.5 时指数是 2，所以平方。

温度在什么时候起作用？

  1. 只在采样时起作用
  2. 只在训练时起作用
  3. 训练采样都起作用
  4. 只在初始化起作用

notebook 只在 sample 里除以 temperature，训练用的损失没有它。所以换温度不用重新训练。

重复背诵也能生成完整句子。要判断模型是否真的学到规律，最该加什么？

  1. 更高的采样温度
  2. 更大的隐藏维度
  3. 更长的序列长度
  4. 独立的验证文本

只有在没见过的文本上损失也低，才说明不是死记。Notebook 没有验证集。
