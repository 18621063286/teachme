RNN 的不合理有效性

一个只会预测下一个字符的网络，靠什么记住上下文，又能记多远。这一包用五课从 "hello" 讲到截断 BPTT，顺手修好 notebook 里几处站不住的结论。

Karpathy 在 2015 年写了一篇很有名的文章：简单的字符级 RNN 能生成像样的文本、代码和 LaTeX。胡嘉玺 notebook 第 2 章把它做成了可以跑的 PyTorch 代码。这一包顺着那份 notebook 讲，每个数字都实际跑过，也因此查出了它的问题：那条漂亮的损失曲线大部分是假象，真实损失中途回弹过。

假定你会 Python，学过一点矩阵乘法和求导，PyTorch API 第一次出现时会讲。按编号往下读，做完该课的练习再进下一课。

五课一条线

先弄清记忆从哪来，再学会判断训练是否真的有效，然后看记忆的边界，最后看怎么用它、怎么解释它。

  1. 同一个 l，两个答案 更新公式和形状，证明没有 W_hh 时损失最低只到 (ln 2)/2。
  2. 那条漂亮的损失曲线是假的 ln V、指数平滑和初值错配，以及被它盖住的回弹。
  3. 截断 BPTT：一行 detach 决定它能记多远 状态往前传，梯度只回传一个窗口。推导衰减，再用实验看边界。
  4. 采样与温度：一个除号做了什么 证明熵随温度单调不减，并分清写作和背诵。
  5. 拆开隐藏状态，核对 notebook 的结论 量化写死的 print，对齐 nn.RNN，看 GPU 何时才有用。含结业作业。

学完能检验的五件事

你能做到在哪一课验收
写出更新公式和每个矩阵的形状，证明没有 W_hh 学不会 "hello"第 1 课，不看笔记写出 step

从 softmax 推出温度的效果，证明熵单调不减第 4 课
修好 notebook，并写成能教给别人的一段话第 5 课结业作业
