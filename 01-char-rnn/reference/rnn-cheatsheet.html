一步

h_t = tanh(W_xh x_t + W_hh h_{t−1} + b_h)

y_t = W_hy h_t + b_y　　p_t = softmax(y_t)

x = torch.zeros(V, 1); x[idx] = 1.0
h = torch.tanh(torch.mm(W_xh, x) + torch.mm(W_hh, h) + b_h)
y = torch.mm(W_hy, h) + b_y

要记住的三件事

  • 矩阵乘 one-hot 等于取一列：W_xh x = W_xh[:, idx]。
  • 所有时间步共用同一套权重，所以参数量与序列长度无关。
  • W_hh = 0 时 h_t 只取决于 x_t。"hello" 上最低平均损失是 ln2 / 2 ≈ 0.3466。

训练时先核对

  • 起点：平均交叉熵应约等于 ln V。V = 24 时是 3.18。
  • 平滑：两个初值的差是 βⁿ(s₀ − s₀′)，和模型无关。β = 0.999 时半衰期约 693 步。总和和平均不要混用。
  • 同时画真实损失，平滑会盖住回弹。
